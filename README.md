# BusinesswithVee website

One-page static site. No build step, no dependencies.

Files (keep them together in the same folder):
- index.html  the whole site (styles are inline)
- veerna.jpg  the photo used in the About section

## Preview
Open index.html in a browser.

## Deploy
Upload this folder to Netlify, Vercel or Cloudflare Pages (static site, no build command, publish directory = this folder). Then add your own domain in the host's domain settings.
